# 机器人消息管理模块（botMessage）

用来让**整个管理组**都能维护「由机器人发出的常驻消息」（社区规则、公告、置顶说明等），
不必再有人单独拿 bot token 去第三方客户端里改。

---

## 一、指令一览

模块只占用 **1 个斜杠指令 + 1 个右键指令**（服务器斜杠指令上限是 100 个，需要省着用）。

### `/机器人消息`

| 子指令 | 作用 |
| --- | --- |
| `编辑` | 修改机器人已发出消息的文字（正文 / 嵌入卡片） |
| `发送` | 用机器人在指定频道发一条新消息 |
| `替换` | 用一条「草稿消息」的内容整体覆盖目标消息（适合长文、复杂排版） |
| `撤销` | 把消息回退到上一次改动之前的版本 |
| `历史` | 查看某条消息的改动记录（谁、什么时候、改了什么） |
| `配置` | 配置可用身份组、操作日志频道 |

### 右键菜单：`编辑机器人消息`

在消息上 **右键 → 应用 → 编辑机器人消息**，是日常最快的入口：

- 纯文本消息 / 只有一张卡片的消息 → 直接弹出编辑窗口
- 多张卡片、或带按钮的消息 → 先弹出一个选择面板，选要改哪一部分

---

## 二、消息怎么定位

凡是需要填「消息」的地方，以下三种写法都支持：

1. **消息链接**（推荐）：右键消息 → 复制消息链接
2. `频道ID-消息ID`：开启开发者模式后右键消息 → 复制消息ID 得到的格式
3. **纯消息ID**：会在当前频道里查找

---

## 三、几条硬性限制（Discord 侧，不是本模块的限制）

- **只能编辑本机器人自己发出的消息。** 别的机器人、Webhook、用户发的消息，Discord 一律不允许本机器人改。
- **消息正文最多 2000 字**；嵌入卡片描述最多 4096 字，但**弹窗输入框最多 4000 字**——
  超过 4000 字的卡片描述无法在弹窗里编辑，请改用 `替换` 子指令。
- **不能给已发出的消息追加/替换附件。** `替换` 只复制文字和嵌入卡片，来源消息的附件不会被搬过去。
- **子区（帖子）被归档或锁定时无法编辑**，需要先解除归档。

## 四、长文 / 复杂排版怎么改

推荐工作流：

1. 管理员在任意频道（比如一个管理组内部频道）把新版规则写成一条**草稿消息**，反复润色；
2. 执行 `/机器人消息 替换 目标消息:<常驻规则消息链接> 来源消息:<草稿消息链接>`；
3. 机器人把草稿的文字与卡片原样搬到目标消息上。

同理，`/机器人消息 发送 形式:复制另一条消息的内容` 可以把草稿直接发成一条新的常驻消息。

## 五、安全设计

- **权限**：服务器所有者 / Discord 管理员 / `core/utils/permissionManager.js` 里配置的管理身份组
  始终可用；其他身份组需要通过 `/机器人消息 配置 操作:添加可用身份组` 加入白名单。
- **可见性**：指令默认只对拥有「管理消息」权限的成员可见。若某个白名单身份组在指令列表里看不到它，
  需要到 **服务器设置 → 整合 → 本机器人 → 权限** 里为该身份组放开。
- **跨服务器保护**：只能操作当前服务器的消息。
- **越权保护**：操作者必须自己能看到目标频道，否则拒绝。
- **提及保护**：编辑已发出的消息时一律不触发提及（`allowed_mentions: {parse: []}`），
  改个错别字不会把 `@everyone` 重新推送一遍。发新消息时默认同样不推送，需要真 @ 到人时把
  `允许提及` 设为 `是`。
- **链接预览不受影响**：正文含链接时 Discord 自动生成的预览卡片会被识别并跳过，
  既不会被误当成可编辑卡片，也不会在编辑时被固化成真正的嵌入卡片。
- **面板消息提醒**：目标消息若带按钮 / 选择菜单（多半是投票、自助身份组、赛事等系统的面板），
  会在编辑前提示——改文字不会破坏按钮，但对应系统刷新面板时可能覆盖你的改动。

---

## 六、留痕与回滚

- 每次改动都会把**改动前后的完整快照**写入 `data/botMessage.sqlite`，每条消息保留最近 30 个版本。
- `/机器人消息 撤销` 回退最近一次改动；再执行一次相当于「重做」。
- `/机器人消息 配置 操作:设置操作日志频道` 之后，每次编辑 / 发送都会在该频道留一条记录
  （操作人、目标消息跳转、变更前后摘要）；改动前内容较长时会附带完整 `.txt` 备份。

## 七、文件结构

```
src/modules/botMessage/
├── index.js                          # 模块启动 + 按钮/弹窗交互路由
├── commands/
│   ├── botMessage.js                 # /机器人消息（编辑/发送/替换/撤销/历史/配置）
│   └── editBotMessageContext.js      # 右键菜单「编辑机器人消息」
├── components/
│   └── messageModals.js              # 各类模态窗口构建 + 颜色解析 + customId 常量
├── services/
│   ├── botMessageService.js          # 核心逻辑：编辑/发送/替换/撤销/日志
│   └── botMessageDatabase.js         # SQLite：配置 + 改动历史
└── utils/
    ├── botMessagePermissions.js      # 权限判定
    └── messageResolver.js            # 消息链接解析、拉取、快照、rich embed 过滤
```

接入点：

- `src/core/index.js`：注册两个指令 + `startBotMessageSystem()`
- `src/core/events/interactionCreate.js`：按 `botmsg_` 前缀转发按钮与弹窗交互
